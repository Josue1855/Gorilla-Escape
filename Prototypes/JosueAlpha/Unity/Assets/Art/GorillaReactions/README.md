# Reacciones del gorila

`gorilla_reacciones_sprite_sheet.png` contiene 16 cuadros transparentes organizados en una cuadrícula de 4 columnas por 4 filas.

## Distribución

| Fila | Reacción | Cuadros |
|---|---|---|
| 1 | Enojado | frente anticipando, frente reaccionando, espalda anticipando, espalda celebrando/molesto |
| 2 | Burlándose | frente sonriendo, frente haciendo burla, espalda mirando sobre el hombro, espalda sacudiendo hombros |
| 3 | Triste | frente preocupado, frente desanimado, espalda con hombros caídos, espalda con cabeza baja |
| 4 | Feliz | frente emocionado, frente celebrando, espalda reaccionando, espalda con brazos levantados |

## Importación sugerida en Unity

- Texture Type: `Sprite (2D and UI)`
- Sprite Mode: `Multiple`
- Filter Mode: `Bilinear`
- Compression: `None` durante la integración
- Conservar el canal alfa

El archivo mide 1402 × 1122 px. Para conservar todo el trazo de acuarela, conviene delimitar los cuadros manualmente desde Sprite Editor en vez de recortar automáticamente los bordes.
