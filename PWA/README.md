# Control React

React + Vite. Componentes UI en src/; conexiones en src/connection/. El shell inicial comprueba el servidor, no incorpora jugadores ni solicita sensores. Build incorpora recursos propios y service worker sin cachear APIs; no CDN.

Guía: [TEAM_START](../docs/TEAM_START.md). npm ci, npm test y npm run build dentro de PWA. Lockfile obligatorio. npm run dev mantiene host localhost y proxy Java:8080. Android/iPhone requieren pruebas HTTPS reales.
