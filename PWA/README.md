# Control React

React + Vite. Componentes UI en src/; conexiones en src/connection/. El shell React comprueba el servidor; el adaptador Software/Lab en src/input y el capturador en spikes/sensors prueban admisión/input RTC y permisos/eventos sintéticos. No constituyen onboarding físico final. Build incorpora recursos propios y service worker sin cachear APIs; no CDN.

Guía: [TEAM_START](../docs/TEAM_START.md). npm ci, npm test y npm run build dentro de PWA. Lockfile obligatorio. npm run dev mantiene host localhost y proxy Java:8080. Android/iPhone requieren pruebas HTTPS reales.

Estado y evidencia consolidada: [auditoría final](../docs/PHASE0_FINAL_AUDIT.md). Android/iPhone físicos permanecen diferidos.
