# Servidor local Java

Spring Boot Web MVC, JDK 21. Hosting/health y DTOs de protocolo; no base de datos, cloud ni gameplay. La salida PWA/dist se incorpora al JAR en build; ejecutar primero el build web.

Guía: [TEAM_START](../docs/TEAM_START.md). Tests unitarios de contrato e integración HTTP real; publicación frontend y recuperación 404. WebSocket/sesión/IPC y empaquetado JRE son siguientes tareas de Fase 0.
