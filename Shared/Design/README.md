# Island expedition assets

The menu, browser controller and native controller share the forest/sand/amber palette, angular forms, expedition route illustration and gorilla-hand seal.

- `island-route.png`: original polygon illustration of the castaway, shipwreck and escape route.
- `island-seal.png`: original angular hand stamp identifying the gorillas' trials.
- `LilitaOne.ttf`: Lilita One by Juan Montoreano; see `LICENSE-Lilita.txt`.
- `NunitoSans.ttf`: static weight 600 instance of Nunito Sans, generated from the upstream variable font; see `LICENSE-Nunito.txt`.

Build and copy the assets with `python3 tools/design/build_brand.py`. Fonts are bundled locally; no runtime font service is needed. The original variable font is retained here for reproducibility. The menu retains the credited low-poly game models under their existing attribution.
