# Biblioteca visual de Jungle Party

Esta carpeta reúne los modelos, texturas e imágenes usados por el prototipo para que el equipo pueda encontrarlos sin recorrer la estructura interna de Unity.

- `models-and-textures/`: modelos FBX/GLB, materiales y texturas exportados para los minijuegos.
- `images/`: fondos, ilustraciones y recursos 2D.

Los archivos pesados se almacenan con Git LFS. Después de clonar la rama, ejecutar `git lfs pull` para descargarlos.

La copia que Unity importa y utiliza permanece en `Unity/Assets`. Esta biblioteca es para consulta, reutilización y nuevas iteraciones del equipo.
